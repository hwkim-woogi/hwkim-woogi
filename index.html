* 토큰은 GitHub API 호출 시에만 사용되며, 저장소 코드(`index.html`)에는 절대 포함되지 않고 현재 기기 브라우저(`localStorage`)에만 저장됩니다.

JSON 데이터 파일 직접 백업 / 복원

GitHub 개인 웹페이지(Pages) 개설 및 토큰(PAT) 발급 1분 가이드
1단계: GitHub 저장소 생성 및 웹페이지 게시

GitHub에서 새 Repository(예: weight-tracker)를 만들고, 이 코드가 담긴 index.html 파일을 업로드합니다. 저장소의 Settings → Pages → Branch를 main으로 선택 후 Save하면 나만의 웹사이트 주소(https://아이디.github.io/weight-tracker)가 생성됩니다.

2단계: 데이터 저장용 토큰(Personal Access Token) 발급

GitHub 우측 상단 프로필 클릭 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token으로 이동합니다.

  • Repository access: Only select repositories (방금 만든 저장소 선택)
  • Permissions (Repository permissions): Contents 항목을 찾아 Read and write로 설정
  • 생성된 github_pat_... 토큰을 복사하여 위 입력칸에 붙여넣고 저장하세요.
3단계: 배지 클릭으로 언제든 수동 커밋!

체중을 기록한 뒤 상단의 수동 GitHub 동기화 배지를 클릭하면 저장소 내부의 data/weight-records.json 파일이 자동으로 생성·업데이트되어 PC와 스마트폰 어디서든 같은 데이터를 불러올 수 있습니다.
